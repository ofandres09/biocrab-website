# Integración pendiente de referencias externas

La revisión permanece abierta hasta incorporar las imágenes externas exactas y comprobar el sitio público indicado por su responsable.

## Recursos disponibles

El archivo recibido `biocrab-assets.zip` contiene seis fotos originales y un archivo de identidad anterior. Las seis fotos están integradas. La marca tipográfica BioCrab se conserva según la elección expresa del responsable.

Las referencias externas descritas como Pinterest no están como archivos en ese ZIP, en `public/images` ni en las carpetas de adjuntos disponibles. La biblioteca `lib/media.ts` conserva los nombres y roles previstos, pero una asignación de nombre no equivale a una imagen cargada.

## Información necesaria

- URL pública exacta del sitio revisado.
- Archivos de las referencias en un ZIP o enlaces a las imágenes concretas.

No se ha descargado una imagen distinta para presentarla como una referencia del responsable. Cuando estén disponibles las fuentes, se incorporarán a sus secciones con las etiquetas y el contexto apropiados; no se presentarán referencias conceptuales como fotografías experimentales de BioCrab.

## Comprobación del despliegue

La compilación de esta revisión responde con `X-BioCrab-Design: full-frame-v2`. Este encabezado permite distinguirla de versiones anteriores al comprobar la URL pública, sin añadir texto técnico a la interfaz del sitio.

El repositorio no declara una página principal ni despliegues en la información pública de GitHub consultada durante esta revisión. El push a `main` confirma el código subido, no una publicación web externa.
